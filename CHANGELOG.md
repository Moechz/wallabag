# Changelog

All notable user-visible changes to the docker TOS application package.

## 2.6.14-1 — 2026-11-11

### Added
- First release. docker (`wallabag/wallabag:2.6.14`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8062 and running
  as a non-root user (65534:65534).
- Persistent data is kept under `/Volume1/DockerAppData/wallabagdocker/`.
